# Casa 3D — Spotify login

Static OAuth PKCE return page for tablet pairing by phone on the same Wi-Fi. No backend, analytics, client secret or application source.

The page receives a temporary authorization code and state, clears them from browser history, and offers a user-initiated navigation to the private tablet address encoded in state. Only the tablet has the PKCE verifier and can exchange the code. Refresh/access tokens stay in Android encrypted storage. Do not paste credentials into this page.

Hosted at https://ghustavuu.github.io/casa3d-spotify-login/
